IMPORTANT WORDPRESS HEADER / FOOTER FIX
If the body updates but your old header/footer remains:
1. Elementor → Theme Builder.
2. Find old Header and Footer templates.
3. Remove the 'Entire Site' display condition OR set them to Draft.
4. Elementor → Tools / Editor → Tools → Clear Files & Data.
5. Clear WordPress cache, host/server cache and CDN cache.
6. Check in an Incognito window.
7. Appearance → Themes must show 'PaiBand Studio 2026 Studio v3.3' as ACTIVE.
