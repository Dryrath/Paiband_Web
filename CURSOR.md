# Cursor Quick Start

Cursor automatically has project rules under:

```text
.cursor/rules/paiband-theme.mdc
```

Before large edits, read:

```text
README.md
docs/EDITING-GUIDE.md
```

Useful prompts:

```text
Edit only the copy in page-about.php.
Do not change section order or CSS classes.
Run validation afterward.
```

```text
Move the gallery section in front-page.php below the Games section.
Do not rewrite either section.
```

```text
Add a team member to the end of the $paiband_team array in page-team.php.
Use assets/team-09-name.jpg.
Do not change the existing team order.
```
